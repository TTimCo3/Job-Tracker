# Internship Tracker

## Summary
An app that is designed to help track internship applications. It is meant to provide a place for the user to easily add and catalogue their applications.
Removing and adding as neccessary.

## Why?
This provides a means for me to learn full-stack programming, as well as help me organize my own internship applications.

## Tech Stack
 - React
 - FastAPI
 - PostgreSQL
 - SQLAlchemy

## Current Features
 - Create applications
 - Edit applications
 - Delete applications
 - Track application status
 - Store company and job information
 - Store application notes and dates
 - Persistent PostgreSQL database
